## 3. 本版改了什么

### 3.1 政策脉冲可交易覆盖（pulse_v9）
- 点对点（PIT）基准动量脉冲分级：FULL / EARLY / MILD / NONE
- MILD 仅在危机压力下；EARLY 过滤弱势熊市反弹
- FULL 不使用虚假看涨评分地板
- 极端 NATR 非脉冲风险上限

### 3.2 轮动选择与风险
- 恢复权重仅对 PULSE_FULL / PULSE_EARLY
- 脉冲期硬排除黄金/公用事业等防守塞满
- 因果当前路径回撤限仓（不看未来）
- 薄宇宙时沪深300（510300）宽基兜底

### 3.3 官方验收口径
- 样本改为近五年（不再以 2017–2019 全历史绝对回撤疤作为唯一否决）
- 隔离目录验收 21/21 后促进到 rtifacts/calibration/
